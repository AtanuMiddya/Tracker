# Setup (all free)
1. GitHub: create a repo, upload these files (keep the .github folder), then Settings > Pages > Deploy from branch > main / root.
2. Drive sync: script.google.com > New project > paste Code.gs > Deploy > New deployment > Web app > Execute as Me, Access: Anyone > copy URL > paste in site Setup tab.
3. WhatsApp: save +34 644 51 95 23 as a contact, send it "I allow callmebot to send me messages" on WhatsApp. It replies with your API key.
4. Repo Settings > Secrets > Actions: add CALLMEBOT_KEY (the key) and SITE_URL (your Pages link). Run the workflow once from the Actions tab to test.
